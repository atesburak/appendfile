# appendfile
Since I have way too much storage at home and a whole bunch of photos/videos I take with the camera, including underwater, I needed an easier way to upload them to storage. The first iteration is simply taking the target folder as an input, otherwise uses the current folder, followed by the input file and then the prefix. The prefix is searched in the target folder and the latest numbering for images or videos are found and the source file is moved to the destination with the prefix+(max-number+1).original-extension format. Not sure if I'll have to iterate on this one but if I do the next steps would possibly be bulk operations whenever I have some time later on. 

Never trust my code but also everyone is free to use this thing without any limitations.
